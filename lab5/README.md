# F. 5

|                  |                                      |
|------------------|--------------------------------------|
| Time limit       | 15 seconds                           |
| Memory limit     | 1 GB                                 |
| Input            | standard input or `input.txt`        |
| Output           | standard output or `output.txt`      |

Find the longest common substring of two strings using a suffix tree.

## Input format

Two strings, one per line.

## Output format

The length of the longest common substring on the first line, then all possible common substrings of that length in lexicographic order without duplicates.

## Example

**Input:**

```text
xabay
xabcbay
```

**Output:**

```text
3
bay
xab
```
