\CWHeader{Лабораторная работа \textnumero 5}

\CWProblem{
Необходимо найти самую длинную общую подстроку двух строк с использованием суффиксного дерева.

{\bfseries Вариант задачи:} поиск наибольшей общей подстроки.

На вход подаются две строки. На первой строке вывода нужно распечатать длину максимальной
общей подстроки, затем перечислить все возможные варианты общих подстрок этой длины
в порядке лексикографического возрастания без повторов.
}
