\section{Conclusions}

By completing this laboratory work for the course \enquote{Discrete Analysis}, I implemented
the search for the longest common substring of two strings using a generalized suffix tree.
The main part of the work was the implementation of Ukkonen's online algorithm: the active point,
the counter of unprocessed suffixes, edge splitting and suffix links.

To find the answer, the tree is traversed iteratively with an explicit stack, and every node is
marked according to the presence of suffixes of the first and second strings in its subtree.
The deepest node covered by both strings gives the length of the answer, and \texttt{std::set}
ensures that the output has no duplicates and is in lexicographic order.

Testing confirmed the advantage of the suffix tree over dynamic programming: on strings of length
4\,000 the tree is about \textbf{30 times} faster, and on larger sizes the DP is no longer used
because of its quadratic running time.
