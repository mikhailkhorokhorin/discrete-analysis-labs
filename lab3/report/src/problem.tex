\section*{Лабораторная работа \textnumero 2}

Вариант структуры данных: PATRICIA.

Необходимо создать программную библиотеку, реализующую словарь на основе дерева
PATRICIA. В словаре каждому ключу, представляющему собой регистронезависимую
последовательность букв английского алфавита длиной не более 256 символов,
поставлен в соответствие номер от 0 до $2^{64}-1$.

Программа должна поддерживать добавление, удаление, поиск, сохранение словаря в
бинарном виде и загрузку словаря из файла. При ошибках ввода-вывода или повреждённом
формате внешнего файла программа должна печатать строку, начинающуюся с
\texttt{ERROR:}, а рабочий словарь должен оставаться в корректном состоянии.

\section*{Лабораторная работа \textnumero 3}

Для реализации словаря из лабораторной работы \textnumero 2 необходимо провести
исследование скорости выполнения и потребления оперативной памяти. В случае выявления
ошибок или явных недочётов требуется их исправить.

Результатом лабораторной работы является отчёт, содержащий дневник выполнения
работы, выводы о найденных недочётах, сравнение исправленной программы с предыдущей
версией и общие выводы о выполненной работе.

Для исследования использовались:
\begin{itemize}
    \item \texttt{gprof}~--- профилирование времени выполнения;
    \item Valgrind Memcheck~--- проверка ошибок работы с памятью и утечек;
    \item Valgrind Massif~--- оценка пикового потребления памяти;
    \item собственный генератор тестов и benchmark из лабораторной работы \textnumero 2.
\end{itemize}
