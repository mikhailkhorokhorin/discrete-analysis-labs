\section{Conclusions}

During the laboratory works, the PATRICIA data structure was implemented for a dictionary of
string keys, and the quality of the resulting program was studied. Lookup, insertion, removal,
saving and loading of the dictionary from a binary file were implemented.

Profiling with \texttt{gprof} showed that, apart from reading and parsing the input, most of the
time is spent in the removal, lookup and insertion operations, which matches the structure of the
program: these functions traverse the tree by critical bits.

Valgrind Memcheck found no memory leaks and no invalid accesses in the dictionary code. Massif
showed moderate memory consumption: about 7.335 MB of heap memory for a set of $100\,000$ words.

Functional defects of serialization were fixed: loading a missing file, a damaged file or a file
without the correct header, and saving a key of the maximum length of 256 characters. Error
messages became specific, keys are validated, and unknown commands are reported. The benchmark was
also fixed so that the PATRICIA lookup measurement cannot be reduced to an empty loop by the
optimizer.

The main result of the work is that the program became more reliable on erroneous input and is
measured more fairly in the performance tests, while the underlying data structure and its
asymptotic properties remained the same.
