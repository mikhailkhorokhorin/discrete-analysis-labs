\section{Description}

The task is to implement a dictionary based on the PATRICIA tree (Practical Algorithm To Retrieve
Information Coded In Alphanumeric) and then to study the quality of the resulting program.

A PATRICIA tree is a compressed binary trie in which every node stores the index of the critical
bit of the key used for branching. This avoids chains of nodes with a single child and keeps only
the positions where the keys actually differ.

The key feature of the structure is \textit{back edges}: when, during a traversal, the critical
bit index of the next node is not greater than that of the current node, the traversal stops. The
target node of such an edge is the candidate for a full string comparison.

To handle boundary cases correctly, a header node (\texttt{header\_}) with critical bit zero is
used; its left child is the root of the tree. All keys are converted to lower case, which makes
the dictionary case-insensitive. The dictionary supports the operations \texttt{insert},
\texttt{find} and \texttt{remove}, as well as binary saving and loading
(\texttt{saveToFile} and \texttt{loadFromFile}).

\section{Source code}

\subsection{Helper functions}

The function \texttt{extractBit} extracts the $i$-th bit of a string (numbering starts at 1, the
most significant bit of the first byte is bit 1). The function \texttt{firstDifferentBit} finds the
position of the first bit in which two keys differ; the result is used during insertion to
determine the critical bit of the new node. The function \texttt{normalizeKey} converts a key to
lower case, and \texttt{isValidKey} checks that a key is non-empty, consists of English letters
only and is not longer than \texttt{MAX\_KEY\_LENGTH} $= 256$ characters. The functions
\texttt{writeUnsigned} and \texttt{readUnsigned} write and read little-endian integers of a given
width; \texttt{readUnsigned} throws \texttt{PatriciaError} when the file ends too early.

\subsection{Node structure and the tree class}

Every node (\texttt{PatriciaTrie::Node}) stores a key, a value, the critical bit index and pointers
to two children. The field \texttt{size\_} of the class \texttt{PatriciaTrie} tracks the number of
elements. The class is movable but not copyable; errors of file operations are reported with the
exception class \texttt{PatriciaError}.

\subsection{Search}

The function \texttt{searchNode} descends the tree, choosing a branch by the critical bit, until it
meets a back edge. The node found is only a candidate: \texttt{find} additionally performs a full
string comparison and returns \texttt{std::nullopt} if the keys differ.

\subsection{Insertion}

During insertion, \texttt{searchNode} is executed first to find a collision or a reference key.
Then \texttt{firstDifferentBit} computes the critical bit of the new node. After that the tree is
descended again to the insertion position, and the new node is attached with a back edge to itself.

\subsection{Removal}

Removal handles two cases. If the node being removed has a back edge to itself
(\texttt{removeNodeWithSelfLoop}), the parent link found by \texttt{findParentLink} is switched to
the other child. Otherwise (\texttt{removeNodeWithoutSelfLoop}) the node that holds the back edge
to the removed element is found; its data is moved into the removed node, the links are fixed, and
the holder node itself is physically deleted.

\subsection{Serialization}

The file starts with the magic header \texttt{PATRICIA}, followed by the format version
(\texttt{FILE\_VERSION}, 4 bytes) and the number of entries (8 bytes). The method
\texttt{saveSubtree} traverses the tree recursively and writes every node as a triple: key length,
the key itself and the value. The length is stored as \texttt{uint16\_t}, because according to the
statement a key may be 256 characters long. After writing, the stream state is checked, and on
failure \texttt{PatriciaError("failed to write file")} is thrown. The method \texttt{load} reads the
entries into a temporary tree, validates the header, the version, every key and the absence of
trailing data; \texttt{loadFromFile} replaces the current state with \texttt{swap} only after the
whole file has been read successfully.

\subsection{Command processing}

The class \texttt{Dictionary} parses one input line in \texttt{Dictionary::execute}: it splits the
line into tokens, validates the key and the value and calls the corresponding tree operation. File
commands catch \texttt{PatriciaError} and print \texttt{ERROR: } followed by the error message.
The function \texttt{runDictionary} reads the input line by line and prints the responses;
\texttt{main} only sets up fast input and output and calls \texttt{runDictionary}.
