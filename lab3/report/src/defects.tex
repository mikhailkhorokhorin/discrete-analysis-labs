\section{Выявленные недочёты и исправления}

В ходе исследования были устранены следующие проблемы:

\begin{enumerate}
    \item Ошибка загрузки отсутствующего файла: метод \texttt{Load} возвращал успех,
    если файл нельзя было открыть. Исправлено: теперь возвращается ошибка, а программа
    печатает \texttt{ERROR: cannot load}.
    \item Повреждённый бинарный файл мог быть принят частично. Исправлено: загрузка
    выполняется во временное дерево, проверяется полнота каждой записи, а рабочий
    словарь заменяется только после успешного чтения всего файла.
    \item Длина ключа сохранялась в \texttt{uint8\_t}. Для ключа длиной 256 символов
    происходило переполнение. Исправлено: длина хранится в \texttt{uint16\_t}.
    \item Benchmark не фиксировал результат поиска PATRICIA. Исправлено: добавлен
    \texttt{volatile}-счётчик успешных поисков, поэтому компилятор не может удалить
    цикл измерения.
\end{enumerate}
