\section{Тест производительности}
Тест производительности представляет из себя следующее: создаётся 2 одинаковых
массива, один сортируется с помощью алгоритма, который мы реализовали, а другой~---
с помощью стандартной функции \texttt{std::stable\_sort}. Время выполнения обоих
алгоритмов замеряется и сравнивается.

\begin{alltt}
root@794a05b215ca:/workspaces/discrete-analysis-labs# python3 lab1/benchmark/generator.py 100
root@794a05b215ca:/workspaces/discrete-analysis-labs# ./build/lab1/lab1_benchmark < tests.txt
Radix sort time: 108us
STL stable sort time: 150us
root@794a05b215ca:/workspaces/discrete-analysis-labs# python3 lab1/benchmark/generator.py 1000
root@794a05b215ca:/workspaces/discrete-analysis-labs# ./build/lab1/lab1_benchmark < tests.txt
Radix sort time: 1007us
STL stable sort time: 1258us
root@794a05b215ca:/workspaces/discrete-analysis-labs# python3 lab1/benchmark/generator.py 10000
root@794a05b215ca:/workspaces/discrete-analysis-labs# ./build/lab1/lab1_benchmark < tests.txt
Radix sort time: 8856us
STL stable sort time: 14353us
root@794a05b215ca:/workspaces/discrete-analysis-labs# python3 lab1/benchmark/generator.py 100000
root@794a05b215ca:/workspaces/discrete-analysis-labs# ./build/lab1/lab1_benchmark < tests.txt
Radix sort time: 113872us
STL stable sort time: 175208us
root@794a05b215ca:/workspaces/discrete-analysis-labs# python3 lab1/benchmark/generator.py 1000000
root@794a05b215ca:/workspaces/discrete-analysis-labs# ./build/lab1/lab1_benchmark < tests.txt
Radix sort time: 833755us
STL stable sort time: 1627027us
\end{alltt}

Как видно из результатов, поразрядная сортировка опережает \texttt{std::stable\_sort}
на всех размерах входных данных. Это объясняется тем, что асимптотическая сложность
нашего алгоритма составляет $O(n \cdot k)$, где $k = 4$ (количество байт в
\texttt{uint32\_t}) — то есть фактически $O(n)$, тогда как сложность
\texttt{std::stable\_sort} равна $O(n \log n)$. При увеличении числа элементов
с $100$ до $1\,000\,000$ разрыв становится всё более заметным: на миллионе элементов
наш алгоритм работает почти в \textbf{2 раза быстрее}.
