\section{Conclusions}
While doing this laboratory work for the course \enquote{Discrete Analysis},
I learned to implement the radix sort and counting sort algorithms.
I figured out how to sort data byte by byte using the type \texttt{std::uint32\_t}
as the key, and how to compactly encode a date as a numeric value
for efficient comparison. I also recalled how to write a template dynamic array
and apply the rule of five.
